# MLBB Fast-Hand Swap Trainer

Live app: **https://screenatyouruse.github.io/mlbb-swap-trainer/**

Interactive muscle-memory drill for MLBB late-game fast-hand equipment swaps:
- **Triple Swap (20 steps):** Boots → Immortality → Winter Crown (`Frozen`) → Scroll Attack list → Rose Gold Meteor
- **Double Swap (12 steps):** Boots → Immortality → Winter Crown (`Frozen`)

## Controls
- **Training / Ranked** mode toggle (`⚙` menu)
- **Realistic / Strict** hitbox mode (`⚙` menu)
- **Fullscreen:** Tap `⛶` (or press `F` on desktop)
- **Restart:** Tap `↻` (or press `Space` / `R` on desktop)
- **Mobile fullscreen app tip:** Open in Chrome on Android, tap **⋮ → Add to Home screen** to launch in landscape fullscreen without the browser bar.
