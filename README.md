## What This Actually Does

A zero-dependency static muscle-memory trainer built straight from 23 native `1560×720` MLBB screen frames:

- **❄ Triple Swap (20 steps):** Boots → Immortality → Winter Crown (`Frozen`) → Sell Winter → Attack Tab → **Swipe Up** → Rose Gold Meteor → Exit (`X`)
- **⚡ Double Swap (12 steps):** Boots → Immortality → Winter Crown (`Frozen`)

## Controls
- **Modes (`⚙` menu):** `🎓 Training` (golden pulse guides + swipe indicator) vs `⚡ Ranked` (unobstructed HUD)
- **Hitboxes (`⚙` menu):** `👍 Realistic` (MLBB thumb padding) vs `🎯 Strict` (exact button bounds)
- **Fullscreen:** Tap `⛶` (or `F` on PC) — on Android Chrome, use **⋮ → Add to Home screen** for a chromeless landscape app
- **Restart:** Tap `↻` (or `Space` / `R` on PC)
- **Stealth in class:** Tap `⚙` → **🔊 Sound: OFF** before the professor looks over
